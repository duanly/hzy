# 方言语音包（可选）

浏览器自带的 TTS 只有普通话 / 粤语 / 国语，**没有衡阳话、耒阳话**；而且不少手机上根本发不出人声
（没装中文引擎、微信一类的内置浏览器、系统 TTS 被关掉……）。录一套自己的，所有机型就都一样了。

**推荐从后台传**：`/admin` → 「语音包」，一次选一批 mp3 拖进去，文件名对上就自动归位，
存在服务器的 `data/voice/`，重新部署不会丢。也可以直接把文件丢进这个目录（随包发出去的那一份）。

**不用录全**：录了哪条用哪条，没录的自动退回 TTS。建议先录动作那几条
（碰 / 吃 / 开跑 / 提龙 / 笑起 / 胡了 / 该你出牌），牌名那 20 条最费工夫，可以放到最后。

## 动作

| 文件名 | 内容 |
|---|---|
| `start.mp3` | 开始 |
| `peng.mp3` | 碰 |
| `chi.mp3` | 吃 |
| `pao.mp3` | 开跑 |
| `ti.mp3` | 提龙 |
| `long.mp3` | 提龙（手里三张摸到第四张，跟 ti 同一句） |
| `wei.mp3` | 笑起（偎，衡阳话就叫笑起） |
| `hu.mp3` | 胡了 |
| `zimo.mp3` | 自摸，胡了 |
| `pass.mp3` | 过 |
| `foul.mp3` | 违规 |
| `liuju.mp3` | 黄庄 |
| `your_turn.mp3` | 该你出牌 |
| `can_hu.mp3` | 可以胡了 |

## 牌名

- 小写一～十：`s1.mp3` … `s10.mp3`（读「小一」…「小十」）
- 大写壹～拾：`b1.mp3` … `b10.mp3`（读「大壹」…「大拾」）

## 录音建议

- 单声道、44.1kHz、64~96kbps mp3 就够，每条控制在 1 秒以内。
- 前后别留空白，否则听起来拖沓。
- 手机上第一次出声要先点一下屏幕（浏览器限制），进场次那一下就已经解锁了。
